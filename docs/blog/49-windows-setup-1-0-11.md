## Что исправлено

**Установка больше не обрывается в Windows Sandbox.** Мастер ждал `cmd.exe` по PID,
а в песочнице `cmd` завершается с кодом 1, пока PowerShell ещё ставит библиотеки:
установщик считал настройку проваленной и откатывал файлы. Теперь мастер ждёт файл
`setup-progress.done` и показывает ход настройки.

**Страницы после входа не отдают 500.** Во встроенном Python нет базы часовых
поясов: `ZoneInfo("Europe/Moscow")` падал с `ZoneInfoNotFoundError`, и дашборд
умирал сразу после логина. В комплект добавлен `tzdata`, а код при его отсутствии
откатывается на фиксированный UTC+3.

**Служба стартует на встроенном Python.** `python312._pth` не кладёт папку скрипта
в `sys.path`, поэтому `import wsgi` падал — теперь корень CRM добавляется явно.

**Синтаксическая ошибка не попадёт в EXE.** Перед компиляцией выполняется
`python -m compileall` по `app/`.

## Оформление

- Мастер всегда на русском, на английской Windows язык не спрашивается.
- Логотип «Ника Сервис» — заставка мастера, значок окна и `Setup.exe`, шапка,
  страница «Возможности» и страница с прогресс-баром.
- На рабочем столе три ярлыка: **Открыть CRM**, **Перезапустить сервис**,
  **Ника Сервис — Сайт**. Остальное — в меню «Пуск».
- «Резервная копия базы» показывает окно с полным путём к архиву и папкой
  `%ProgramData%\NikaCRM-backup`.

## Проверено в Windows Sandbox

Установка и работа проверены на чистой Windows Sandbox (Windows 11, без сети):

- установка — код 0, службы `NikaCRM-Web` и `NikaCRM-PostgreSQL` в состоянии Running;
- вход `admin` / `111111` и дашборд — 200;
- создание заявки, реестр заявок и карточка заявки открываются;
- три ярлыка на рабочем столе и десять в меню «Пуск»;
- перезапуск службы и удаление.

## Установка

Один EXE для Windows 10/11 x64, внутри Python 3.12 и PostgreSQL 18. Ставится
поверх предыдущей версии без потери базы; чужой Python и PostgreSQL не трогает.
Запускать от имени администратора, окно не закрывать 5–10 минут.

Подробно: [руководство § 2.3](/docs/guide).
