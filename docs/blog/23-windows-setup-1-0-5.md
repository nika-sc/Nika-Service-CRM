## Что изменилось относительно 1.0.4

### Доступ из локальной сети
- CRM слушает не только `127.0.0.1`, но и LAN.
- `TRUSTED_HOSTS` / `@private` корректно принимают локальные IP (в т.ч. IPv6 Host).
- Firewall: правило с профилем Any + запасной `netsh`.

### Почта (SMTP)
- Демо-отправитель `noreply@example.com` из bootstrap больше не ломает Mail.ru (`550 not local sender`).
- При отправке подставляется логин, если «От кого» — заглушка.
- В **Настройки → Почта** — предупреждение, таблица провайдеров и проверка «От кого» = логин.
- Исправлена ошибка теста письма директору (`NameError: parseaddr`) после правки SMTP.
- Пустой SMTP больше не подменяется на `localhost` (на Windows это давало `WinError 10061`).
- Email директора сохраняется при тесте; демо `director@example.com` не принимается.
- Сохранение почты/«Общих» больше не сбрасывает чекбоксы «Уведомления клиентам».
- При установке в `%ProgramData%\NikaCRM\.env` добавляется пустой блок `MAIL_*`; сохранение почты в UI обновляет эти ключи.
- После сохранения SMTP на Windows Offline — предупреждение перезапустить службу ярлыком «Nika CRM — Перезапуск службы».
- Плейсхолдеры «От кого»: `Название вашей компании <ваш@email.ru>` (email = логин).
- Гайд: [USER_GUIDE § 13.5](/docs/guide#135-почта-smtp), [smtp-mail-setup](/blog/smtp-mail-setup).

## Установка

Запуск EXE **от имени администратора** → ярлык **Nika CRM — Открыть** → `http://127.0.0.1:5000` или `http://<LAN-IP>:5000`. Демо-пароли `111111` смените сразу.
