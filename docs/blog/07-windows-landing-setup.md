# Windows SETUP, SEO-лендинг и установка на VPS

Июль 2026: проще поставить CRM и понять продукт с первого экрана.

## Windows

- Офлайн SETUP для Windows 10/11 x64: встроенный PostgreSQL, служба, ярлыки, демо-база.
- Зеркало установщика на демо-сайте.

## Лендинг

- Публичная главная с галереей, входом в демо и ссылками на документацию.
- SEO: meta/OG, sitemap, хлебные крошки; рабочие разделы CRM закрыты от индексации.

## Linux / VPS

- Скрипты bootstrap и one-shot `linux_setup.sh` для Ubuntu.
- Безопасное обновление живой базы: `linux_upgrade.sh` (архив → миграции → без перезаписи `.env`).
- Помощь с установкой на FirstVDS по партнёрской схеме (см. README).
