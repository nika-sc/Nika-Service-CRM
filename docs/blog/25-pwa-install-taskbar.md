# Установка PWA и закрепление на панели задач Windows

Август 2026: как поставить Nika CRM как приложение в Chrome/Edge, закрепить на панели задач и добавить иконку на телефон.

## Зачем

PWA открывает CRM в отдельном окне без адресной строки — удобнее, чем вкладка браузера. На Windows можно закрепить иконку рядом с обычными программами; на телефоне — ярлык на главном экране.

Нужен **HTTPS** (демо `https://service.nika-crm.ru/` или ваш сервер). На голом `http://localhost` браузер часто не предлагает установку.

Полный раздел в руководстве: [USER_GUIDE § 18](/docs/guide#18-мобильный-доступ-и-pwa).

## Desktop: Chrome / Edge

1. Откройте CRM по HTTPS.
2. В адресной строке нажмите **«Установить»** или меню **⋮ → Установить приложение…**.
3. Подтвердите в диалоге.

![Кнопка «Установить» в Chrome](assets/walkthrough/42-pwa-chrome-install.png)

![Диалог установки](assets/walkthrough/43-pwa-chrome-dialog.png)

4. Запустите приложение из «Пуск» или ярлыка. На панели задач: **ПКМ по иконке → «Закрепить на панели задач»**.

![Закрепление на панели задач](assets/walkthrough/44-pwa-windows-taskbar.png)

## Мобильный

В Chrome или Safari: «Поделиться» / меню → **«На экран „Домой“»** (или «Добавить на главный экран»).

![Добавить на главный экран](assets/walkthrough/45-pwa-mobile-add-home.png)

## Ограничения

- Это не полноценный offline-клиент: без сети заявки и касса могут быть недоступны.
- Service Worker кэширует только часть статики.
- Push в чате — отдельно: VAPID на сервере и разрешение браузера.
