# PostgreSQL и продакшен-контур

CRM переведена на **PostgreSQL** как единственную рабочую СУБД: пул соединений, миграции, бэкапы `pg_dump`.

## Что изменилось

- `DB_DRIVER=postgres` и `DATABASE_URL` для разработки, демо и продакшена.
- Bootstrap-дамп без персональных данных клиентов для быстрого старта.
- Автобэкапы на VPS с сжатием; согласование major-версии клиента `pg_dump` с сервером.
- Docker Compose: web + nginx + postgres (образ 18+).

SQLite остаётся только как наследие в старых сценариях и не используется для новых установок.
