# LAN, квитанция и предварительная стоимость

8 августа 2026: закрыли пять замечаний от пользователей офлайн-установки и приёмки.

## Доступ к CRM из локальной сети

Раньше Windows SETUP слушал только `127.0.0.1`, а `TRUSTED_HOSTS` не знал LAN-адрес. С другого ПК в той же сети страница не открывалась.

Теперь новая установка:

- слушает все интерфейсы (`APP_HOST=0.0.0.0`);
- в `TRUSTED_HOSTS` стоит токен `@private` (любой private/loopback IP) плюс имя ПК;
- брандмауэр Windows открывает порт 5000 для профилей Private и Domain.

С другого устройства: `http://192.168.x.x:5000`. Демо-пароли (`111111`) смените сразу — CRM видна всей сети.

Уже установленную копию чинит ярлык **Nika CRM — Доступ по сети (LAN)** или скрипт `enable-lan-access.ps1`.

На Linux: `scripts/linux_setup.sh --lan` (или `--with-nginx`). В `.env` bootstrap пишет `@private`.

## Пароль PostgreSQL в Windows SETUP

`111111` — только для демо-логинов CRM (`admin`, `manager`, …), не для pgAdmin. Пароли базы случайные на каждую установку. Ярлык **Nika CRM — Пароль базы данных** печатает host, port, user и пароли из `%ProgramData%\NikaCRM\installer\install-state.json`.

## Внешний вид / комплектация в квитанции

В форме приёмки это одно поле с тегами. В квитанции по ошибке было две строки, и «Комплектация» всегда пустая. Теперь в шаблоне одна строка **«Внешний вид / комплектация»**.

## Предварительная стоимость

Рядом с предоплатой на форме новой заявки — поле оценки. Оно печатается в квитанции (`##ESTIMATED_COST##`), в кассу не проводится. Удобно показать клиенту ориентир, если потом скажет «вы говорили дешевле».

## Размер шрифта в шаблонах

При сохранении шаблона квитанции или письма `bleach` без CSS-санитайзера вычищал `font-size` из `style`. Теперь стили типографики сохраняются; в редакторе на `/settings` есть кнопка размера шрифта.
