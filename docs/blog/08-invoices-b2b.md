# Счета для юрлиц и ИП

Модуль **«Счета»**: выставление счетов организациям и ИП с печатью документов и связью с оплатой заявки.

## Зачем

Раньше оплата в CRM шла только через кассовые платежи. Для B2B нужны счёт, акт и накладная с реквизитами продавца и покупателя — без потери связи с закрытием заявки и зарплатой.

## Что умеет

- Реестр счетов: статусы черновик / не оплачен / оплачен / отменён.
- Создание из заявки (снимок услуг и товаров) или вручную.
- Реквизиты продавца (банк, подпись, печать, логотип) в **Счета → Настройки**.
- Клиент: тип физлицо / ИП / юрлицо, ИНН; опционально автозаполнение через DaData.
- Печать HTML: счёт, акт (услуги), накладная (товары) — «Без НДС» в v1.
- **Оплачен** по счёту с заявкой → платёж `transfer` / `captured`; долг заявки обнуляется, закрытие и ЗП работают как обычно.
- Счёт **без заявки** при «Оплачен» уходит в **магазин** (продажа + касса + списание склада); на карточке счёта показывается алерт. ЗП по заявке не затрагивается.
