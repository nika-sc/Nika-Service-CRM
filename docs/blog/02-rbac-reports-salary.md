# Права доступа, отчёты и зарплата

Когда в системе работают несколько ролей, нужны границы доступа и прозрачный расчёт мотивации мастеров.

## RBAC

- Роли и права: просмотр/редактирование заявок, склада, кассы, отчётов.
- Индивидуальная настройка прав пользователя поверх роли.

## Отчёты

- Сводный дашборд, прибыль, остатки, касса, журнал действий.
- Позже — сводка дня для директора.

## Зарплата

- Начисление по статусам заявки (флаги «начисляет зарплату» / финальный статус).
- Дашборд зарплаты, связь с полной оплатой заявки.
- Защита от повторного начисления и корректный пересчёт при возвратах.
