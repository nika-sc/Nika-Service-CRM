# Настройка почты (SMTP): Mail.ru, «От кого» и демо-адрес

Август 2026: подробный гайд по SMTP в Nika CRM — что писать в каждом поле и почему Mail.ru отклоняет `noreply@example.com`.

## Где настраивать

**Настройки → Общие настройки → Почта (SMTP)** (`/settings#mail-smtp`).

При сохранении почты в CRM значения также пишутся в `.env` (если файл найден: Windows `%ProgramData%\NikaCRM\.env`, Linux — корень установки). На новой установке в `.env` уже есть пустой блок `MAIL_*` (шаблон `scripts/templates/mail.env.snippet`).

Переменные `MAIL_*` в `.env` нужны бэкапам/службам и как запасной источник, если в БД поля пустые.

![Чеклист](assets/walkthrough/41-smtp-checklist.png)

## Правильный пример (Mail.ru / BK.ru)

| Поле | Значение |
|------|----------|
| SMTP-сервер | `smtp.mail.ru` |
| Порт | `587` |
| TLS | вкл. |
| SSL | выкл. |
| Логин | `ваш@bk.ru` |
| Пароль | пароль **приложения** из Mail.ru |
| От кого | `Название вашей компании <ваш@bk.ru>` (тот же email) или пусто |

На **Windows Offline** после «Сохранить» перезапустите службу ярлыком **«Nika CRM — Перезапуск службы»** на рабочем столе — иначе SMTP из `.env` может остаться прежним до рестарта.

![Корректная форма](assets/walkthrough/39-smtp-mailru-correct.png)

## Частая ошибка

В демо-базе «От кого» бывает заполнено так:

`Nika CRM Demo <noreply@example.com>`

Логин уже поменяли на реальный ящик, а «От кого» забыли — SMTP отвечает:

`550 not local sender over smtp` с адресом `noreply@example.com`.

![Неверный отправитель](assets/walkthrough/40-smtp-sender-mismatch.png)

Исправьте «От кого» на тот же mailbox, что логин, сохраните и повторите тест письма директору.

В актуальном коде демо-отправитель при отправке подменяется логином, но поле в настройках лучше поправить явно.
