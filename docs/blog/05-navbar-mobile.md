# Навбар и мобильный интерфейс

Май 2026: единое главное меню с подменю и корректная работа на телефоне.

## Интерфейс

- Полноценный navbar с разделами CRM и выпадающими пунктами.
- Адаптация подменю под узкий экран (гамбургер).
- Левый сайдбар: быстрые иконки, чат, профиль.
