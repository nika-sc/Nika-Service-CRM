## Что нового в 1.0.6

### Почта (SMTP) на Windows
- После **сохранения** настроек почты CRM показывает предупреждение: перезапустите службу ярлыком **«Nika CRM — Перезапуск службы»** на рабочем столе.
- Без рестарта служба может держать старые `MAIL_*` из `.env` — тест письма «как будто не сохранилось».
- В форме SMTP понятнее плейсхолдеры: `Название вашей компании <ваш@email.ru>` (email внутри `<>` = логин).
- Гайд: [USER_GUIDE § 13.5](/docs/guide#135-почта-smtp), [smtp-mail-setup](/blog/smtp-mail-setup).

## Что вошло ещё с 1.0.5 (LAN, SMTP, квитанции)

### Доступ из локальной сети
- CRM слушает не только `127.0.0.1`, но и LAN.
- `TRUSTED_HOSTS` / `@private` корректно принимают локальные IP (в т.ч. IPv6 Host).
- Firewall: правило с профилем Any + запасной `netsh`.

### Почта (SMTP)
- Демо-отправитель `noreply@example.com` из bootstrap больше не ломает Mail.ru (`550 not local sender`).
- При отправке подставляется логин, если «От кого» — заглушка.
- В **Настройки → Почта** — предупреждение, таблица провайдеров и проверка «От кого» = логин.
- Пустой SMTP больше не подменяется на `localhost` (на Windows это давало `WinError 10061`).
- При установке в `%ProgramData%\NikaCRM\.env` добавляется пустой блок `MAIL_*`; сохранение почты в UI обновляет эти ключи.

### Заявки и квитанции
- Предварительная стоимость: валидация и корректное сравнение в журнале изменений.
- Квитанция: внешний вид и комплектация в одной логике; размер шрифта в шаблонах сохраняется.

## После установки

1. Ярлык **Nika CRM — Открыть** → `http://127.0.0.1:5000` или `http://<LAN-IP>:5000`.
2. Настройки → Почта: заполните SMTP → **Сохранить**.
3. Ярлык **Nika CRM — Перезапуск службы** → повторите тест письма.
4. Смените демо-пароли (`111111`).
