# Шаблоны диагностики в заявке

22 августа 2026: в Nika Service CRM для диагностики заявки можно подставить готовый текст, а не набирать его каждый раз с нуля.

## Зачем это мастеру

Перед статусами вроде «Готов» и «Закрыт» нужен сохранённый текст диагностики — его видит клиент в личном кабинете. Шаблон экономит время: типичные заключения (чистка, ремонт, осмотр) уже в системе, остаётся выбрать и при необходимости поправить.

## Как пользоваться в заявке

1. Откройте заявку → **«Диагностика»** (или дождитесь окна при смене статуса).
2. Сверху поле поиска: начните вводить название или фрагмент текста.
3. Выберите шаблон — текст подставится в поле. В поле останется **название** выбранного шаблона.
4. Другой шаблон **заменяет** предыдущий, а не дописывает снизу.
5. Нажмите **«Сохранить текст»**. Фото (JPEG/PNG/PDF) не обязательны; загрузка снимков не стирает несохранённый текст.

Сначала в списке шаблоны этой **модели**, затем марки и типа устройства, затем общие (без привязки).

## Где править список

**Настройки → Шаблоны диагностики.** У шаблона: название, текст и по желанию тип / марка / модель (пустые поля — подходит для любых устройств). Правка справочника — у сотрудника с правом настроек.

В комплекте уже есть типичные тексты: чистка игровой приставки, ноутбука и ПК, ремонт МФУ и другие. Их можно изменить под ваш СЦ или добавить свои.

Клиент в кабинете видит только сохранённый текст и фото, не список шаблонов.
