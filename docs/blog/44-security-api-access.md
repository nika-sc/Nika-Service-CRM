# Обновили систему безопасности

12 сентября 2026: в Nika Service CRM обновили систему безопасности — границы ролей сотрудников и ответы без входа стали аккуратнее.

Сотрудник видит только то, что положено его роли. Личный кабинет клиента по-прежнему отдельный от кабинета сотрудника. Программы и вкладки без входа получают отказ, а не страницу логина.

Как работать изо дня в день: [руководство](/docs/guide), [сценарий дня](/docs/walkthrough).

Демо: [service.nika-crm.ru](https://service.nika-crm.ru/).
