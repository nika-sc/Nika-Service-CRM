# Производительность, касса по статьям и мобильное меню

Июль 2026: ускорение CRM на WORK/DEMO, исправление периодов в отчётах, сводка кассы по статьям и меню на телефоне.

## Производительность

- Несколько воркеров gunicorn (типично 3×4 на WORK, 2×4 на DEMO).
- Redis в Docker: общий кэш, rate limit и шина Socket.IO между воркерами.
- Nginx отдаёт `/static/` с диска и кэшем; реестр заявок и DataTables облегчены (счётчики, FTS-поиск).

Без Redis (малый VPS) приложение стартует на in-memory кэше.

## Отчёты: период «Прошлый месяц»

Исправлен расчёт дат на 31-м числе месяца: раньше «Прошлый месяц» мог дать `date_from` позже `date_to` и пустой отчёт. На сервере границы периода дополнительно меняются местами, если пришли перевёрнутыми.

## Касса: суммы по статьям

На `/finance/cash` можно выбрать статью (например «Обед»), увидеть сумму за период и таблицу **итого по всем статьям**. Удобно сверять расходы за месяц.
