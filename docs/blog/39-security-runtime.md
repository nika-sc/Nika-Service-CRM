# Обновили систему безопасности

22 августа 2026: в Nika Service CRM обновили систему безопасности — вход, загрузки и работа контейнера стали аккуратнее для повседневной работы.

## Что изменилось для сотрудников

Вход в CRM и в личный кабинет клиента по-прежнему раздельные: сессия сотрудника не подменяет кабинет клиента. В чате сотрудников принимаются обычные документы и картинки, без архивов. Загрузка логотипа и печати для счетов сохраняется только в каталог печати.

Страницы входа оформлены так, чтобы браузер не выполнял лишний код со стороны. Для самохостинга Docker-контейнер приложения работает не от root.

Как работать изо дня в день: [руководство](/docs/guide), [сценарий дня](/docs/walkthrough).

Демо: [service.nika-crm.ru](https://service.nika-crm.ru/).
