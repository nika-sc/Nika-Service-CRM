## Windows Offline SETUP 1.0.11 (2026-10-24)

Автономный установщик Nika CRM для Windows 10/11 x64.

Файл: `packaging\windows\output\NikaCRM-Offline-Setup-1.0.11-x64.exe`
(412 861 025 байт / 394 МБ).

SHA256: `E548A135C58D61A02BF815A26E0D357CCC74A205E46BDFC58874A70488AF1652`

Ссылки на GitHub Releases и зеркало добавляются после публикации.

### Нумерация

1.0.11 — первая рабочая сборка после 1.0.10. Сборки 1.0.12–1.0.16 остались
внутренними итерациями при отладке установщика и не публиковались.

### Что исправлено

**Установка больше не обрывается в Windows Sandbox.** Мастер ждал завершения
`cmd.exe` по PID. В песочнице `cmd` выходил с кодом 1, пока PowerShell ещё ставил
библиотеки, поэтому установщик считал настройку проваленной, откатывал уже
скопированные файлы и сохранял недописанные логи (`console.txt` пустой,
`setup.log` обрывался на строке pip). Теперь мастер ждёт файл
`setup-progress.done`, который пишет сам `bootstrap.ps1`, показывает проценты и
имеет таймаут 20 минут.

**Служба NikaCRM-Web запускается на встроенном Python.** Изолированный
`python312._pth` не добавляет папку скрипта в `sys.path`, из-за чего
`import wsgi` падал, а проверка `http://127.0.0.1:5000/login` не проходила.
`service_entry.py` теперь вставляет корень CRM в `sys.path` до импорта.

**Страницы после входа больше не отдают 500.** Во встроенном Python нет базы
часовых поясов, поэтому `ZoneInfo("Europe/Moscow")` бросал
`ZoneInfoNotFoundError`, и дашборд падал сразу после логина (страница входа при
этом открывалась — она дат не форматирует). В бандл добавлен wheel `tzdata`, а
`app/utils/datetime_utils.py` при отсутствии базы откатывается на фиксированный
UTC+3 (в Москве нет перехода на летнее время с 2014 года).

**Синтаксическая ошибка не попадёт в установщик.** Перед компиляцией EXE
выполняется `python -m compileall` по `app/`; при ошибке сборка останавливается
(в 1.0.9 в EXE уехал `IndentationError` из `app/routes/orders.py`).

**Диагностика.** В сообщение об ошибке попадает хвост `web-stderr.log` и
`web-stdout.log`; при ограниченном режиме PowerShell (`ConstrainedLanguage`)
установщик сразу объясняет причину, а не падает молча.

**Печать счетов.** Подстановка `##TAG##` переживает форматирование TinyMCE, а
символ валюты отделяется пробелом от суммы (`2000 сом` вместо `2000сом`).

### Оформление и ярлыки

- Мастер установки всегда на русском: `LanguageDetectionMethod=none` и
  `ShowLanguageDialog=no` (на английской Windows язык больше не спрашивается;
  английский остаётся доступен параметром `/LANG=english`).
- Мастер — классический (`WizardStyle=classic`): логотип «Ника Сервис» слева на
  страницах мастера. На странице с прогресс-баром Inno 6.6+ большой логотип не
  рисует вовсе, поэтому туда добавлен отдельный баннер: он ставится в свободное
  место под шкалой прогресса (или над ней, если места нет), размеры считаются по
  геометрии страницы.
- Логотип: заставка мастера (`wizard-large.bmp`), прозрачный значок шапки
  (`wizard-small.png`), значок окна и `Setup.exe` (`nika-service.ico`), картинка
  страницы «Возможности» и страницы установки (`installer-hero.bmp`), иконка
  деинсталлятора.
- На рабочем столе — три ярлыка: **Открыть CRM**, **Перезапустить сервис** и
  **Ника Сервис — Сайт** (`https://nika-sc.ru/`). Их создаёт сам Inno Setup
  (секция `[Icons]`, `{commondesktop}`), без PowerShell и COM — на машинах с
  ограниченной политикой скриптов они всё равно появятся. Остальное — в меню
  «Пуск»: LAN, Пароль базы, Резервная копия, Журналы, Руководство, Онлайн-демо,
  Удалить. При обновлении поверх старой версии установщик удаляет лишние ярлыки,
  которые она успела положить на рабочий стол.
- «Резервная копия базы» больше не закрывается молча: показывает окно с полным
  путём к архиву, его размером и папкой `%ProgramData%\NikaCRM-backup`,
  предлагает открыть папку.

### Проверено

Чистая **Windows Sandbox** (Windows 11, без сети), установка 1.0.11:

- установка — код 0, обе службы в состоянии Running;
- `http://127.0.0.1:5000/login` — 200;
- вход `admin` / `111111` — 200, дашборд открывается;
- создание заявки, реестр заявок и карточка заявки — работают;
- в меню «Пуск» 10 ярлыков, включая «Ника Сервис — Сайт»;
- на рабочем столе ровно три ярлыка: Открыть, Перезапустить сервис, Сайт;
- перезапуск службы — снова 200;
- удаление отработало.

Скриншоты проверки — в `docs/assets/walkthrough/` (файлы `windows-1.0.11-*.png`) и в блоге
`docs/blog/49-windows-setup-1-0-11.md`.
