## Windows Offline SETUP 1.0.12 (2026-11-09)

Статус: исходники обновлены, установщик 1.0.12 пока **не собран и не опубликован**.

### Исправлено

- Socket.IO отключён на клиенте. Gunicorn работает sync-воркерами и не
  поддерживает WebSocket, из-за чего браузер получал 400 и мог зависать
  при переключении вкладок. Чат и уведомления работают через
  HTTP-синхронизацию (12 с / 60 с).
- `import os` в `app/routes/main.py`: сохранение общих настроек больше
  не падает с `NameError`.
- `service-worker.js`: `CACHE_NAME` поднят до `v4`, старый JS не залипает.
- `staff_chat.js` подключён через `static_url()` с `?v=<mtime>`, чтобы
  обновление подхватывалось с первой перезагрузки.

### Проверено

- `python -m compileall app`;
- `pytest tests/test_bootstrap_pg_migrations.py`;
- ручная проверка на клиенте: касса → магазин → склад без зависаний,
  в логах нет новых `socket.io`-запросов.
